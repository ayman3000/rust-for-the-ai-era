Install Rust & First Program

A short first step: install Rust, write fn main(), print x, learn why x = 5; fails, then use mut when a value should change.

Open Quiz View Example Back to Course Hub

1. Install Rust

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
rustc --version
cargo --version

2. First program

fn main() {
    let x = 10;
    println!("{x}");
}

Important: use println!("{x}");, not println!({x});.

3. Immutable by default

fn main() {
    let x = 10;
    x = 5;
    println!("{x}");
}

This does not compile because x is immutable by default.

4. Try to modify an immutable variable

fn main() {
    let x = 6;
    x = x + 1; // ERROR: x is immutable
    println!("{x}");
}

The compiler rejects this. Rust tells you exactly what is wrong:

error[E0384]: cannot assign twice to immutable variable `x` --> immutable_increment_error.rs:7:5 | 6 | let x = 6; | - first assignment to `x` 7 | x = x + 1; // ERROR: x is immutable | ^^^^^^^^^ cannot assign twice to immutable variable | help: consider making this binding mutable | 6 | let mut x = 6; | +++

Fix: add mut and it compiles.

5. Use mut to change it

fn main() {
    let mut x = 10;
    println!("before: {x}");

    x = 5;
    println!("after: {x}");
}

6. Copy x into y

fn main() {
    let x = 10;
    let y = x;

    println!("x = {x}");
    println!("y = {y}");
}

For simple integers, Rust copies the value. So both x and y print 10.

Recap

  • fn main() is where the program starts.
  • let x = 10; creates an immutable variable.
  • x = x + 1; fails because x is immutable — the compiler shows the exact error.
  • x = 5; fails unless x is mutable.
  • let mut x = 10; allows changing x.
  • let y = x; copies simple values like integers.
