Rust Data Types

Understanding Rust's core building blocks: Scalar types (single values) and Compound types (grouped values), and how Rust infers them.

Open Quiz View Example Back to Course Hub

1. Scalar Types

Represent a single value. They are the atoms of the language.

let integer = 100;     // i32 (default)
let float = 3.14;       // f64 (default)
let boolean = true;     // bool
let character = 'R';    // char (Unicode!)

Tip: i32 and f64 are the defaults. Rust knows them automatically.

2. Compound Types

Group multiple values into one type.

// Tuple: mixed types, fixed size
let tup = (500, 6.4, true);
println!("First value: {tup.0}");

// Array: same type, fixed size
let arr = [1, 2, 3, 4, 5];
println!("First value: {arr[0]}");

Arrays in Rust must have a fixed length. If you need a growable list, you will use Vec in later lessons.

3. Type Inference

let x = 5; // Rust knows it's an integer

Rust is statically typed. This means the compiler must know the type of every value at compile time. Most of the time, it guesses correctly (inference), keeping your code clean.

4. Type Annotations 
let x: i64 = 5000000000;
let y: f32 = 3.14;

Use annotations when you need a specific size (like i64 instead of i32) or when the compiler is ambiguous.

Recap

  • Scalar: One value (Int, Float, Bool, Char).
  • Compound: Grouped values (Tuples, Arrays).
  • Static Typing: Types are fixed at compile time.
  • Inference: Rust usually guesses the type for you.
