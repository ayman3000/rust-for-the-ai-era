# Rust for the AI Era

**From ownership to high-performance AI tools.**

A beginner-friendly Rust course by **Ayman Hamed** for developers who want to learn Rust with a practical, modern, AI-era mindset.

This course teaches Rust from the ground up, but always with a builder mentality: clear concepts, runnable examples, recap notes, and interactive quizzes.

## Learning Flow

Every lesson follows the same system:

1. **Watch the video**
2. **Read the recap**
3. **Run the code**
4. **Try the interactive quiz**
5. **Continue only when the concept feels clear**

## Course Promise

Rust can feel strict at first. This course makes that strictness understandable. We learn one concept at a time, run small examples, read compiler feedback, and build a strong mental model.
