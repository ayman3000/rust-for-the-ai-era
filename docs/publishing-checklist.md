# Publishing Checklist

Before publishing a lesson:

- [ ] Code examples compile or intentionally show a compiler error for teaching.
- [ ] README explains the concept simply.
- [ ] Quiz has 20 relevant MCQs.
- [ ] Correct answers are distributed across A/B/C/D.
- [ ] Quiz works locally with no console errors.
- [ ] YouTube description includes quiz link, source code, and official reference.
- [ ] Pinned comment points students to the quiz checkpoint.
